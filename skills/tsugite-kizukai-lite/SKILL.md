# tsugite-kizukai-lite（気遣いの考え方・公開版）

継ぎ手（TSUGITE）の公開版で使う、気遣いの考え方の最小セット。ベテランの「一つひとつの気遣い（葉）」を聞き出し、後任者に渡すときの土台にする。

詳しい型（場面別の言い換え表、全項目のチェックシート、事例、ワーク）は非公開の完全版にあり、このスキルには含めない。

## 使う場面

- 「葉の問い」で、ベテランに選択肢を示して聞くとき
- 後任者が初めて相手に会う前の「最初のひと言」をつくるとき
- 引き継ぎのあいさつ・お礼の文面を整えるとき

## 考え方の芯（3つ）

1. **主語を「自分」から「相手」へ。** 「自分がどう見られるか」ではなく、「相手が今どんな状態で、何に関心があるか」から考える。
2. **気遣いは4ステップ。** 知る → 気付く → 置き換える（「自分なら」ではなく「相手なら」）→ 行動する。完璧より、今できるベストを。
3. **「2回目に会える人」になる。** 引き継ぎで一番もろいのは、最初の1〜2回。2回目に会ってもらえれば、関係は続いていく。

## 葉の問いで使う選択肢（例）

ベテランに「何をしていますか？」と聞くと「特に何も」と返ってきやすい。選択肢を見せて「この中でどれですか？他には？」と聞く。

- 記念日（誕生日・創業記念日・出会った日）にひと言を送る
- お礼をその日のうちに送る
- 近くに行ったら立ち寄る
- 相手の大切な人（社員・家族）を大切にする
- 帰り際、見えなくなるまで見送る
- 写真を撮って、すぐ送る
- 他にありますか？（本人の言葉をそのまま記録する）

## 後任者に渡すときの型

- **最初のひと言**：前任者の名前と、相手が大切にしていることを一緒に添える。
  例：「〇〇から、△△さんには新しい技術のお話を一番に、と聞いてまいりました。」
- **お礼**：その日のうちに、短く。「学ばせていただいたこと」を1つだけ具体的に書く。
- **迷ったら**：相手に聞く。「どんな関わり方ならお役に立てますか？」

## 表現の注意

- 責めるトーンにしない。できていないことより、次にできる一つを示す。
- 気遣いを「察する才能」や「我慢」として書かない。誰でも後から身につけられるものとして書く。
- 実在の人物名・社名は入れない。デモでは架空の名前を使う。
