# 検証：ベテラン本人の答えとの一致率（大工さんの作品 MaestrIA にならった検証）

実施：2026-11-08 深夜。

## 何を測ったか
継ぎ手は、ベテランに聞く前に「たぶんこう答える」という推測（仮説）を立て、選択肢で確かめる。推測が本人の答えに近いほど、ベテランは「そうそう」と答えるだけで済み、外れたときも「いや、実はね」と話してくれる。
そこで、**ベテラン本人が実際に答えた10問**（根3・幹3・葉2・役割2）を正解にして、AIが答えを聞く前に立てた推測が、本人の答えとどれだけ一致したかを測った。

- ベテラン：作り手本人（新人時代に先輩からお客さまを引き継ぎ、大きく広げた営業）。正解は 11/4 に作り手が音声で答えた内容（お客さまは仮名、前職の社名は伏せた）
- 比べた3つ（推測を立てたのは、それぞれ別の、まっさらな Claude）
  - **A 白紙のAI**：問いだけを見て推測する
  - **B 継ぎ手**：それまでに本人が答えた言葉を根拠に、行間を一歩だけ先読みして推測する（画面の「行間を読む推測」と同じ考え方）
  - **C 継ぎ手＋公開版スキル**：Bに、公開版スキル2本（気遣いの考え方・押さない営業の語り口）を足す
- 採点：どれの推測かを伏せた、別の Claude が判定（◎一致2点／△一部1点／×不一致0点。どの営業にも当てはまる一般論だけなら△以下）
- 一致率 ＝ 点数の合計 ÷ 満点（20点）

## 結果
| | 一致率 | ◎一致 |
|---|---|---|
| A 白紙のAI | **30%** | 0問 |
| B 継ぎ手（本人の言葉を根拠に先読み） | **65%** | 4問 |
| C 継ぎ手＋公開版スキル | **75%** | 5問 |

聞けば聞くほど、本人の芯（「他でもない自分だからこそ」）を根拠に次の答えが読めるようになる。白紙のAIは「信頼を落とさない」「全員に会いに行く」のような一般論にとどまった。

## 限り
- 10問・ベテラン1人・1回だけの小さな検証。採点も Claude（条件は伏せた）
- 正解は作り手本人の答えなので、下の「作り手」の列で、採点が本人の感覚と合うかを確かめる【作り手の確認待ち】
- 一致率が高すぎることは目指さない。外れた推測こそ「いや、実はね」を引き出すきっかけになる
